# Misi Pecahan Ceria — One Page Website

Website pembelajaran digital Matematik Tahun 1 menggunakan HTML, CSS dan JavaScript.

## Struktur folder

```text
Misi-Pecahan-Ceria-OnePage/
├── index.html
├── assets/
│   ├── css/
│   │   ├── style.css
│   │   └── responsive.css
│   ├── js/
│   │   ├── main.js
│   │   └── animations.js
│   ├── images/
│   ├── videos/
│   └── icons/
└── README.md
```

## Pautan yang telah dimasukkan

- Video YouTube: https://youtu.be/P5nXxM3ffo8
- Wordwall: https://wordwall.net/resource/124467611?wwmethod=link
- Google Forms: https://forms.gle/XTwF5E33MEi9TzcC9

Video YouTube telah dipasang sebagai embed. Wordwall dan Google Forms menggunakan pautan terus yang dibuka pada tab baharu. Untuk embed Wordwall atau Google Forms di dalam halaman, dapatkan kod embed rasmi daripada fungsi Share/Send pada platform berkenaan dan gantikan kad pautan yang tersedia.

## Cara menjalankan website

1. Muat turun dan ekstrak ZIP.
2. Buka folder `Misi-Pecahan-Ceria-OnePage`.
3. Klik dua kali `index.html` untuk pratonton asas.
4. Untuk pembangunan, buka folder menggunakan Visual Studio Code dan gunakan extension Live Server.
5. Pastikan semua subfolder `assets` kekal pada lokasi asal.

## Fungsi yang telah tersedia

- Top navigation melekat (sticky).
- Navigasi mudah alih.
- Navigasi aktif mengikut bahagian yang sedang dilihat.
- Animasi kemunculan ketika scroll.
- Penerokaan pecahan interaktif: 1/2, 1/4, 2/4 dan 3/4.
- Embed video YouTube.
- Pautan Wordwall dan Google Forms.
- Reka bentuk responsif untuk desktop, tablet dan telefon.
- Sokongan `prefers-reduced-motion`.

## Lokasi untuk mengubah suai

- Reka bentuk dan warna: `assets/css/style.css`
- Saiz dan susun atur skrin: `assets/css/responsive.css`
- Menu, navigasi aktif dan aktiviti pecahan: `assets/js/main.js`
- Animasi scroll: `assets/js/animations.js`
- Kandungan dan pautan: `index.html`

## Nota

Folder images, videos dan icons disediakan untuk aset tambahan yang mungkin dimasukkan kemudian. Website ini tidak memerlukan framework atau library luaran.
